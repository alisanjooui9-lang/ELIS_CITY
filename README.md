ELIS CITY

یک بازی جهان‌باز سه‌بعدی تحت وب که برای اجرا روی موبایل و کامپیوتر طراحی شده است.

امکانات فعلی

- شهر سه‌بعدی قابل گشت‌وگذار
- شخصیت قابل کنترل
- رانندگی با خودرو
- ورود و خروج از خودرو
- خودروهای مختلف در شهر
- NPCهای شهری
- مأموریت و سیستم پاداش
- پول داخل بازی
- نقشه‌ی کوچک
- چرخه‌ی حرکت در محیط
- کنترل لمسی برای موبایل
- کنترل کیبورد برای کامپیوتر
- رابط کاربری فارسی
- اجرای بازی از یک فایل HTML

کنترل‌ها

موبایل

- جوی‌استیک سمت چپ: حرکت
- «ورود»: ورود یا خروج از خودرو
- «عمل»: انجام تعامل و مأموریت
- «دویدن»: افزایش سرعت حرکت
- «نقشه»: نمایش نقشه

کامپیوتر

- "W A S D" یا کلیدهای جهت: حرکت
- "Shift": دویدن
- "E": ورود/خروج و تعامل
- "M": نمایش نقشه

مأموریت

بازیکن باید به نقطه‌ی مشخص‌شده روی نقشه برسد و مأموریت را تکمیل کند.

با انجام مأموریت، پاداش پولی دریافت می‌شود.

اجرا

فایل اصلی پروژه:

ELIS_CITY_single_file.html

برای اجرای بازی، فایل HTML را در یک مرورگر باز کنید.
